Bottom line

The deterministic pipeline recovers ~58–77% of the real on-sheet connections — and the Tier-1 upgrades leave that recall unchanged (the 6 misses are missed in both configs), because the upgrades move false positives, not real-connection recall: the backbone pass trades away precision by inventing off-page links, the line-filter buys some back by removing pipe-label junk. The local Qwen R4 validator can't help — it rejects everything. The biggest recall gap is a specific, fixable cluster: the 4 pump-suction instruments.

Caveat: this ground truth is Opus-traced (a third-signal reference, not certified human GT), scoped to the 3 main equipment clusters, with off-page connections excluded — no single-sheet tracer can reach those (gap #22).

One class fix takes precision from 82.1% to 94.1%. Five of the seven false positives are the same defect: two child devices (instrument / valve / safety_device) related to each other because they share a host or a header. The fix is a natural extension of the single-host rule already in the code — if both endpoints are child-type and they share a host, suppress the edge. No threshold, no tuning, same reasoning that already removed the LSHL/TSH → HAM-0100 wrong-endpoint errors. Removing that class alone gives 32/34 = 94.1% precision, and would leave only the wrong-host case (already flagged automatically) and the duplicate-record case.

Read these numbers with four caveats

Self-adjudicated. The verdicts were made by the same party that wrote the pipeline — a strong third-signal opinion, not certified ground truth (register gap #3+5). Per-claim verdicts and reasoning are saved for spot-checking.

One sheet, hand-assisted. 3 equipment extents were hand-placed and 4 missing entities hand-recovered. And hand placement is itself a tuning knob — the first, tighter boxes lost two real edges before a wider set restored them.

Recall rests on a smaller base than precision. 15 edges across 3 clusters, and the original 26-connection trace was never persisted — so it is a partial reconstruction, unlike the precision figure which covers every claim.

v2 is not yet shown to generalise. On the two other dev sheets, R0's extent resolution drops to 19% and 43% and port detection fails entirely on the sheet whose CAD export outlines its text (1 embedded word). The architecture is tag-name-independent — verified by stripping every tag and getting byte-identical output — but it depends on real symbol locations, which is Molmo2's job and not yet wired in.

What to distrust in these numbers

The Phase 0 regression gate no longer holds, for an understood reason: the tracer now populates passes_through_symbols, so Pass 0 fires on the legacy path for the first time (6,235 of 9,784 segments; 191 of 237 legacy relations). Legacy went 78/52 → 221/95. That is an expected consequence of the inline fix, not a regression — but refactor neutrality can no longer be claimed, and any "the v1 baseline was X" statement must be re-derived rather than quoted.

A retracted claim. While debugging the above it was asserted that the field "was always populated and the earlier 0-of-8,105 measurement was taken on the wrong graph." That is wrong. The original zero was correct at the time; the field became populated because the fix landed. Pass 0 genuinely was dead code before 2026-07-28.

6 new claims are unadjudicated, and 4 fit the sibling pattern the rewritten rule targets. Bounds including everything unresolved: [73.8%, 95.2%].

Two reruns exist and disagree by design. A parallel session reports 33 relations (symbols=30), having excluded 4 hand-recovered pump instruments whose coordinates were never saved to a file. This run includes them (symbols=34). The 33 figure is the more conservative and more reproducible.

Still one sheet, still self-adjudicated. R0's extent resolution drops to 19% and 43% on the other two dev sheets, and port detection fails entirely on the sheet whose CAD export outlines its text. Verdicts came from the same party that wrote the pipeline, and the recall GT is a 15-edge partial reconstruction of a trace that was never persisted.

Closing summary. On one real vector sheet with entity extraction corrected by hand, the deterministic half of Pipeline 3 v2 reaches F1 ≈ 0.90. Boundary edges went from structurally impossible to 16/16 correct and were the strongest component throughout. One clearly identified defect remains (wrong-host binding, already auto-flagged), and the result has not been shown to generalise beyond this sheet. Against PID2Graph — the only multi-sheet benchmark with real ground truth — the pipeline sits at F1 0.225 versus a 0.226 nearest-neighbour floor, but that is the raster path on a corpus with a documented tracing ceiling and is not comparable.
